# Skills (заготовка)

Здесь будут описания повторяемых навыков для задачи P008-T008 (лендинг VPN).

## Структура
skills/<имя-навыка>/SKILL.md

## Формат SKILL.md
- name: короткое имя
- description: когда применять
- входные данные
- шаги
- критерии готовности

## Кандидаты
- [ ] landing-from-mockups: вёрстка лендинга по макетам
- [ ] telegram-wishlist: блок вишлиста и переход в Telegram-бота
- [ ] hosting-deploy: размещение на хостинге (без хранения секретов в репозитории)
- [ ] task-status-report: отчёт о статусе этапов по README

## Правила
- Термин «вишлист» не заменять на waitlist.
- Не хранить доступы, токены и IP-адреса в файлах.
