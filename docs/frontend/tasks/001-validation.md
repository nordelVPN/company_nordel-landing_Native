# FRONT-001 — Проверка текущей реализации

Статус: внесены визуальные правки; полная приёмка не закрыта.

## Что проверено

Все шесть исходных PNG просмотрены визуально. Интерфейс и данные страницы на английском. Исправлены фон и вертикальные отступы hero, контуры гор, отдельная иллюстрация телефона, положение телефона, отступы текста приложения и карточек тарифов, круги шагов в тёмной теме.

Успешно выполнены development- и production-сборки Webpack и ESLint (`src webpack`). Production проверен в установленном Google Chrome 157.0.8103.79 через Playwright:

- 375, 768 и 1440 px, светлая и тёмная темы;
- отсутствие горизонтального переполнения и элементов текста за границами viewport;
- мобильное меню с клавиатуры, Escape и восстановление фокуса;
- демо подключения и информационные кнопки;
- открытие вишлиста, удержание фокуса и закрытие Escape;
- системная тема, ручное переключение и сохранение после перезагрузки;
- reduced motion и видимый outline;
- отсутствие ошибок JS, консоли и загрузки ресурсов.

## Артефакты

[Машинный отчёт](../qa/front-001/chromium/report.json). В том же каталоге сохранены полные снимки на трёх ширинах и `light-screen-N.png` / `dark-screen-N.png` с наложениями `-overlay.png` и разностями `-difference.png` для N=1,2,3.

Размеры сравнений берутся из самих PNG. Перед снимком восстанавливается начало страницы. Секции временно скрываются только в тесте, чтобы сопоставлять отдельные экраны концепта; рабочая страница остаётся единым лендингом.

Повторный запуск с установленным Chrome:

```sh
npm run build:prod
node scripts/verify-landing.cjs chromium chrome
```

Без третьего аргумента скрипт использует браузер Playwright. Отдельный Chromium Playwright на момент проверки отсутствовал; установка не выполнялась.

## Оставшиеся различия и ограничения

- Шапка единая для всего лендинга; концепты показывают разные варианты наличия Explore the app и расположения навигации.
- В тёмном концепте приложения светлый текст на белом телефоне почти не читается. В реализации оставлен тёмный текст; это сознательное отличие для рассмотрения при приёмке.
- Отдельные иконки пока текстовые символы; их начертание, сглаживание шрифта, оттенки, тени и небольшие геометрические различия не дают полного пиксельного совпадения.
- Число meanChannelDifference служит диагностикой, а не критерием визуальной приёмки.
- Firefox и WebKit в этом проходе не проверялись. Проверки выше не заменяют полный аудит доступности и контраста.
- Адрес Telegram-бота не задан; вишлист остаётся демонстрационным.

## Локальный просмотр

При начале проверки localhost:3000 отдавал старый русский каркас из ранее запущенного процесса. Этот процесс остановлен. Попытка фонового запуска через командный инструмент не дала доступного сервера. Для просмотра текущей версии запустить `npm run start` в локальном терминале проекта и открыть http://localhost:3000. Обе сборки на диске актуальны.
