# FRONT-002 — Переключение языка без перезагрузки

Статус: реализовано; проверено в Chrome. Проверки Firefox/Safari остаются открытыми.

## Задача

Единый модуль `src/modules/i18n.js` переключает EN/RU и заменяет фразы на главной и About. Английский остаётся языком по умолчанию. Словарь `src/data/locales.json`: верхний ключ — язык, далее плоские пары `key: value`.

## Контракт разметки

- `data-i18n="hero.title"` — текст конкретного элемента через textContent.
- `data-i18n-aria-label`, `data-i18n-placeholder`, `data-i18n-title`, `data-i18n-content` — перевод соответствующего атрибута.
- `data-language-select` — переключатель; варианты берутся из словаря.
- Сложные заголовки и кнопки: отдельный span для фразы, иконки и br остаются соседними узлами. HTML из JSON не вставляется.
- Повторяющиеся элементы получают ключ с индексом, например `features.0.title`.
- Динамическое превью использует `t(key)` и событие `languagechange`; состояние подключения сохраняется.

## Этапы

1. Словарь EN/RU и единый контроллер с fallback на EN.
2. Разметка всех фраз, метаданных и доступных имён на обеих страницах.
3. Сохранение выбора в localStorage, обновление html lang, восстановление при переходе и перезагрузке; отсутствие storage не ломает переключение.
4. Проверка сборок, линтера, переключения туда/обратно, динамических состояний, вишлиста, вложенной разметки и адаптивности.

## Критерии приёмки

Перевод применяется без перезагрузки; ключи словарей совпадают; переключение не сбрасывает тему, меню и превью; не удаляет иконки и обработчики. Неизвестный язык заменяется EN, неизвестный ключ сохраняет исходную фразу. При выключенном JS доступен английский HTML.

## Границы

Переводы RU — рабочая редакция. Названия Nordel, Essential, Plus, Family и цены не переводятся. Юридические ссылки остаются #. Переключение в браузере не создаёт отдельных индексируемых языковых URL; многоязычная SEO-маршрутизация — отдельная задача.

## Реализация и поддержка

- Контроллер: `src/modules/i18n.js`, подключён первым модулем обеих страниц через `webpack/pages.js`.
- API: `t(key)`, `translate(root)`, `setLanguage(code)`. Событие `languagechange` отправляется на document, код языка доступен в `event.detail.language`.
- Выбор хранится в `localStorage['nordel-language']`. По умолчанию EN; неизвестный язык возвращает EN.
- Чтобы добавить фразу, добавьте одинаковый ключ в оба раздела JSON и поставьте `data-i18n="section.key"` на элемент только с текстом. Для кнопки с иконкой размечайте отдельный span.
- Для атрибутов используйте `data-i18n-aria-label="key"` и аналогичные атрибуты из контракта выше.
- Превью меняет ключи при подключении; смена языка обновляет текущие надписи без сброса состояния.
- Переведены главная, About, header/footer, вишлист, title/description и доступные имена элементов. Базовый английский HTML сохраняется без JavaScript.
- JSON включается в сборку Webpack. После изменения переводов необходима пересборка.
- При добавлении динамической разметки вызывайте `translate(container)`.

## Проверка реализации

Production-сборка и ESLint прошли. Автоматическая проверка в установленном Chrome: 12 сценариев (главная/About × 375/768/1440 px × светлая/тёмная тема) прошли.

Проверены: совпадение наборов ключей EN/RU; соответствие размеченных текстов и атрибутов русскому словарю; переключение обратно на EN; title; сохранение RU после перезагрузки; открытие/закрытие вишлиста; сохранение подключения превью при смене языка; отсутствие горизонтального переполнения и ошибок JavaScript.

Не проверены отдельно: Firefox/Safari, недоступный localStorage, смена языка при открытом модальном окне, визуальное соответствие всех русских переносов. Эти проверки не считаются пройденными.
