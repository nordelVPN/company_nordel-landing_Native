# Роль: Разработчик Telegram-бота

- **Цель:** бот с вишлистом и его развитие.
- **Зона:** команды, сценарии, рассылки, хранилище подписчиков, поддержка.
- **Входы:** механика вишлиста, токен бота (вне репозитория).
- **Выходы:** код в `tg-bot/`, описание команд.
- **Границы:** оплаты и тарифы вне задачи.
- **Готовность:** подписка проходит сквозной тест с сайта.
