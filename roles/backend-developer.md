# Роль: Backend-разработчик

- **Цель:** единый API для бота и приложений.
- **Зона:** авторизация, аккаунты, выдача конфигураций, база данных.
- **Входы:** требования от бота и клиентов, связка серверов.
- **Выходы:** API-спецификация и сервис.
- **Границы:** тарифы и оплаты — отдельная задача; секреты не в коде.
- **Готовность:** спецификация согласована с клиентами.
