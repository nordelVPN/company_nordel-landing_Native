# Роль: DevOps / релизы

- **Цель:** развёртывание и публикация всех компонентов.
- **Зона:** хостинг, домен, HTTPS, размещение через офшорные IP, CI/CD, мониторинг, резервные копии, публикация в магазинах.
- **Входы:** доступы к хостингу (пока не переданы), сборки от разработчиков.
- **Выходы:** работающие окружения, инструкции без секретов.
- **Границы:** конкретные адреса и доступы хранятся вне репозитория.
- **Готовность:** компонент доступен после деплоя и может быть откачен назад.
