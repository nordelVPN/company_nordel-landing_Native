# Роль: iOS-разработчик (iPhone)

- **Цель:** iPhone-приложение и его развёртывание.
- **Зона:** UI, Network Extension для VPN, вход через API, сборка, TestFlight, App Store.
- **Входы:** API, дизайн, Apple Developer аккаунт, Mac с Xcode (не в репозитории).
- **Выходы:** код в `ios/`, сборка в TestFlight.
- **Границы:** без серверной логики.
- **Готовность:** работает на реальном iPhone, проверены правила App Store для VPN.
