# Роль: QA

- **Цель:** проверка каждого компонента и связки между ними.
- **Зона:** тест-план, сквозной сценарий «сайт → бот → приложение», регресс, баг-репорты.
- **Входы:** сборки, макеты, требования.
- **Выходы:** чек-листы и отчёты о дефектах.
- **Границы:** не меняет код и не закрывает этап без подтверждения владельца.
- **Готовность:** критичных дефектов нет, чек-лист пройден.
