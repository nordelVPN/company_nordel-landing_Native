# Роль: Desktop-разработчик (macOS, Windows)

- **Цель:** клиенты для macOS и Windows.
- **Зона:** UI, VPN-клиент/драйвер на каждой ОС, устанщики, подпись и автообновление.
- **Входы:** API, дизайн, сертификаты подписи (не в репозитории).
- **Выходы:** код в `macos/` и `windows/`, установочные пакеты.
- **Границы:** без серверной логики. Если нужны нативные клиенты, роль можно разделить на macOS и Windows.
- **Готовность:** установка и подключение на чистых машинах обеих ОС.
