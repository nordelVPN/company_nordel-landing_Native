# Роль: Веб-разработчик

- **Цель:** лендинг по макетам с вишлистом для юзеров в телеграм бота.
- **Зона:** вёрстка, адаптив, блок вишлиста, ссылка на бота. Термин «вишлист» не менять.
- **Входы:** макеты, адрес бота, домен (пока не сообщены).
- **Выходы:** готовый сайт в `site/`.
- **Границы:** без бота и бэкенда; размещение делает с DevOps.
- **Готовность:** соответствует макетам, работает на мобильных.
