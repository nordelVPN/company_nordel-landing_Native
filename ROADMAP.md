## Выполнено по бэкенду Telegram-вишлиста

- [x] PHP webhook, /health, обработка /start и JSON-хранилище без дублей пользователей.
- [x] Docker Compose: сайт, PHP-бот, отдельный ngrok и постоянный volume.
- [x] Панель ngrok на localhost:4040, автоматический выбор публичного dev domain.
- [x] PHP-команды set/info/delete для webhook и инструкция ручного тестирования.
- [x] Проверены PHP-синтаксис, конфигурация Compose, сборка образа, HTTP-ответы и запись данных.
- [ ] Зафиксировать сквозной тест с сайта через Telegram и сохранность данных после перезапуска.
- [ ] Подготовить production-развёртывание и дальнейшее развитие бота.

Подробности: [отчёт](docs/backend/status.md), [инструкция](docs/backend/docker-compose.md). Единый API, авторизация и серверная часть VPN в этот результат не входят.

## Зависимости (предварительно)
- Бот даёт механику вишлиста для сайта: сайт зависит от первого этапа бота.
- Приложения зависят от серверной части и API (связка серверов, тарифы, оплаты вне этого плана).
- Развёртывание Android/iOS: аккаунты магазинов, подписи, политики. Нужно проверить допустимость VPN-приложений в App Store и Google Play.

## Общие открытые вопросы

- Бюджет, сроки, исполнители.
